# BlueStuff — Game Test Reports

Public, automatically-generated GLI-19 pre-certification test reports for games built on the BlueStuff Game Studio platform.

Each file under `reports/` is produced by an independent, open test engine and published **unmodified — including any failures**. Reports cover the seven statistical tests named in GLI-19 §3.2.2 (RNG distribution, independence, RTP) plus an adversarial source review. These are pre-certification quality checks, not a substitute for certification by an accredited testing laboratory.
